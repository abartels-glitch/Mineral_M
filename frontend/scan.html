Scan a part's Data Matrix code

Take or choose a photo of the Data Matrix printed on a part (generated at credential issuance — see index.html) and it resolves straight to that credential's passport, no login required. On a phone, this opens the camera directly; on desktop, it opens a file picker. Decoding happens entirely in the browser via ZXing, vendored locally under frontend/vendor/ rather than a CDN — the photo is never uploaded to the server.
