Upload a certificate of conformance / MTR

MVP only supports one document type (per the pinned document-scope decision). A certificate can cover one heat or several (a consolidated multi-heat certificate) — each heat is reviewed and issued as its own credential. PDFs are read via their embedded text layer, not image OCR (see README). Plain text files also work, for the demo samples.
