The private key was generated in this browser and marked non-extractable — it never leaves this device and this app never has access to it, only to the public key and the signatures it produces. Losing this browser profile means losing the ability to sign with this key; the only recovery is registering a new one.

Generate & register a new signing key

Generates a fresh Ed25519 keypair in this browser and registers the public key with the platform. This replaces this browser's local key — if one was already registered, the previous key stops being valid for new issuance the moment this one is confirmed (its past credentials remain fully verifiable either way).
